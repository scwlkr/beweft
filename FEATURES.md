# Features

Everything below is planned; the project currently contains no application.

- **Publishing workspace:** Buffer-inspired composer, drafts, queues and
  calendar for multiple brands and channels.
- **Connections:** Owner-supplied social provider credentials and direct
  integrations, subject to each provider's available access and capabilities.
- **Results and conversations:** Analytics and an inbox where supported by the
  provider, with clear unavailable and partial states.
- **Agent access:** API and practical CLI/MCP access to the same actions used
  by the web interface.
- **Self-hosting:** An always-on scheduler and documented installation, storage,
  authentication, backup, restore, and upgrade paths.
