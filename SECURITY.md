# Security

beweft is self-hosted. Report vulnerabilities privately to the maintainer via
GitHub security advisories; do not open public issues for undisclosed
vulnerabilities.

## Scope

- Owner authentication, setup secrets, OAuth tokens and provider credentials
- Cross-brand/workspace data isolation
- Publication recovery and duplicate-prevention guarantees
- Media upload and storage handling

## Out of scope

- Vulnerabilities in third-party providers or self-hosted infrastructure
- Issues requiring physical access to the server

## Supported versions

Only the latest release on `main` receives security fixes.
